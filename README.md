# mini-ultrasonic-radar
This is the firmware for a small radar built around the classic Arduino Nano, just to make it "mini"
**Arduino Radar System**

A DIY radar project using an Arduino Nano, an HC-SR04 ultrasonic sensor, an SH1106 OLED display, an MG90S servo motor, a WS2812B LED, and a buzzer. It detects nearby objects, displays distance and radar graphics, and provides visual and sound alerts.
📡 **Arduino Radar System**

The main purpose of this project is to detect nearby objects and estimate their distance and direction using an ultrasonic sensor mounted on a rotating servo motor. An OLED displays radar graphics and distance readings, while an LED and buzzer provide visual and sound alerts to help identify nearby obstacles.
